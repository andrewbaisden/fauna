# AI-assisted engineering

Fauna was planned in Cursor Plan mode from a product brief, then implemented in vertical slices.

## Human responsibilities

- Product direction and non-goals (not a Pokémon clone)
- Stack choices (Better Auth, Leaflet, no IUCN runtime API)
- Architecture approval
- Scientific caution: ranges, provenance, original prose
- License policy for 3D and photography
- Review of generated code, security and deployment

## AI-assisted responsibilities

- Scaffolding Next.js, Prisma schema, seed pipeline
- Domain functions and tests
- App Router pages and feature UI
- Documentation drafts
- Catalogue expansion YAML from structured facts

## Verification

Agents must run typecheck, unit tests and the seed. 3D models must be inspected for license and visual honesty (the elephant mesh is stylized, not a living-animal scan).
